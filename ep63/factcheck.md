# Ep 63 fact-check (raw vs boiled egg spin)
Checked 2026-11-26.

| # | Claim | Verdict | Note / source |
|---|---|---|---|
| 1 | Raw egg, stopped briefly, starts turning again | VERIFIED | Exploratorium: "the hard-cooked egg will remain stationary, but the raw egg will start spinning again." https://annex.exploratorium.edu/cooking/eggs/activity-spin.html |
| 2 | Boiled egg stopped the same way stays still | VERIFIED | Same page. Keep "stays still" (source says stationary). |
| 3 | Finger stops only the shell; liquid keeps moving | VERIFIED | Exploratorium: "the liquid inside didn't stop moving when you stopped the shell." |
| 4 | Moving liquid drags the shell back around | VERIFIED | Same page: liquid drags shell back into rotation (friction between liquid and shell). Wording "drags" matches the source. |
| 5 | Boiled egg is solid, all stops at once | VERIFIED | Exploratorium; Scientific American: cooked egg's solid contents move with the shell. https://www.scientificamerican.com/article/raw-or-cooked-that-is-the-question/ |
| 6 | How to tell raw from boiled without cracking | VERIFIED | NASA JPL activity and Exploratorium describe it as this test. https://www.jpl.nasa.gov/edu/teach/activity/planetary-egg-wobble-and-newtons-first-law/ |
| Opt | Boiled egg spun fast rises on its end (Moffatt and Shimomura, Nature 2002) | REMOVE from description unless re-checked | Search returned the Nature news item and Cambridge page, but I did not read the paper's wording. Nature news: https://www.nature.com/doifinder/10.1038/news020325-6 ; https://www.cam.ac.uk/node/21448. Use only as "a fast-spinning boiled egg can stand on end" if kept. |

Narration lines: all accurate. "It's not a sloppy stop" is an editorial rebuttal, fine. Description should say "stop it for a moment" (the restart needs the liquid still moving, so a brief stop works; a long hold lets it slow).

# Ep 64 claims (ruler drop test: reaction time in centimetres)
Physics: a ruler released from rest falls d = g t^2 / 2 (g = 9.81 m/s^2, air drag negligible over 0.3 s). Worked numbers: 0.1 s -> 4.9 cm; 0.2 s -> 19.6 cm; 0.247 s -> 30 cm; 0.3 s -> 44.1 cm.
